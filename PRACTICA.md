# Semana 07 · Clínica de Brote

Esta versión contiene un fallo intencional. La app abre, pero el filtro de estado no devuelve las tareas esperadas.

## Tu investigación

1. Instala con `npm ci`; ejecuta lint, tipos y pruebas.
2. Guarda tu nombre para identificar la demostración.
3. Crea dos tareas de la misma materia con estados diferentes.
4. Prueba los filtros Todas, Pendiente y Completada. Anota esperado/observado.
5. Formula una hipótesis, localiza la causa y corrige el comportamiento sin quitar el filtro.
6. Repite la prueba combinando búsqueda, materia, prioridad y estado.
7. Configura tu propio proyecto EAS. No uses identificadores de proyecto de otra persona.

## Entrega

Incluye un breve diagnóstico (síntoma, causa, cambio y verificación), evidencia de los controles locales y una demo personalizada.

- Android: APK preview instalado y adjunto a GitHub Releases. Compartir el enlace de una release privada requiere que el docente tenga acceso.
- iOS: build preview para simulador y demostración Appetize, con Metro apagado.
- Comprueba nombre, tarea propia, horario, tema y persistencia. En Appetize conserva la misma sesión para probar datos locales.

El docente dispone de otros ejercicios aislados. RN (S20) y Taller 0701/0702 se incorporarán con sus enunciados oficiales; este ejercicio no pretende sustituirlos.
